# CALCULADORA-DE-MATRIZES
Uma empresa de tecnologia necessita de uma ferramenta computacional para executar operações matemáticas com matrizes utilizadas em aplicações de engenharia, análise de dados e processamento numérico.  Desafio  Desenvolva, em linguagem C, um sistema interativo que permita ao usuário cadastrar duas ou mais matrizes e realizar operações matemáticas.
